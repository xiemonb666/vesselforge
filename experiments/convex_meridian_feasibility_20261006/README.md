# Convex meridian feasibility prototype

This is an inert, source-only alternative to the earlier SLSQP search. Importing the module does not load SciPy. A future call to run_feasibility(root_ready=True) would make at most one scipy.optimize.linprog(method="highs") call for each of the two default families, after the case_authorized flag in source_pins.json is explicitly changed to true. Both gates currently prevent a solve, and this review did not call that entry point or calculate geometry.

The inputs are pinned in vesselforge/tmp/review_20261006/convex_meridian_feasibility_20261006/source_pins.json. They include the frozen semantic seed and source, the fixed-case source, the explicit design_cases.json with bowl apex height 72 mm and the unchanged jar, and the previously reviewed curvature source. The seed was hash-checked only during this source review; its numeric JSON payload was not read. The implementation constructs an exact RREF-compatible control set Q0 and exact nullspace directions Z, then represents controls as Q0 + Z alpha.

For each span, the rational reference direction e_i is formed from the sum of the old seed's two endpoint velocity poles, divided by that vector's L1 norm. This gives ||e_i||_2 <= 1. Its strictly positive speed floor is s_i = max(1 mm/global-u, 0.5 * (old-seed span chord dot e_i) / h_i). The source computes these values from pinned input only when a future authorized run is requested; no per-span numeric values were computed for this source-only handoff.

The LP constrains every extracted Bezier pole to the radius/height box; every velocity pole to nonnegative height and the correct radial sign around the apex; and every velocity pole on every span to e_i dot v >= s_i. For side spans 1 through 10, each acceleration pole satisfies all four signed inequalities +/-a_r +/-a_z <= s_i^2 / 9.09, which is exactly ||a||_1 <= s_i^2 / 9.09. Flat base and cylindrical neck spans retain pole bounds, monotonicity, fixed poles, and the projection regularity gate, while receiving no acceleration constraint.

The full-span proof uses the Bernstein convex-hull property. At every parameter value, each velocity and acceleration is a convex combination of its poles. Thus the pole inequalities imply e_i dot v >= s_i, ||v||_2 >= s_i, and ||a||_2 <= ||a||_1 <= s_i^2 / 9.09 throughout each screened span. Therefore |kappa| = |det(v,a)| / ||v||_2^3 <= ||a||_2 / ||v||_2^2 <= 1 / 9.09, continuously across the whole span. The output independently reports the existing exact P_R certificate at R=9; an unknown P_R result does not invalidate this separately proved 9.09 mm bound.

The objective is min sum(abs(alpha)), represented with 15 nonnegative epigraph variables. Solver floats are converted from their decimal spellings to exact Fraction values, then every LP row is rechecked exactly. The exact verifier also checks feature equalities, C4 joins, pole bounds, monotonicity, straight base/neck exclusions, strict endpoint conditions, and the full-span L1/projection proof. An LP failure or decimal recheck failure is not a proof that the original vessel problem is infeasible: these are conservative sufficient constraints and the LP has only one attempt per family.

The planned execution envelope is one LP per family, a 20 second HiGHS time limit per family, a shared 60 second ceiling, and an output below 8 MiB. The earlier 80-iteration SLSQP route is not reused. A future authorized runner should enforce the wall limits externally as well as using the solver time limit.

Before loading the numeric seed or constructing the RREF model, the entry point rejects an existing result and acquires a run_started.json marker using exclusive file creation. A second call is refused. Every returned LP candidate retains its exact decimal alpha, all 17 reconstructed controls, the exact fixed direction/speed-floor table, and—if exact rows fail—the violation count plus the ten most negative exact margins. The planned checker is read-only and is not run in this handoff.

This produces only an offline canonical geometry candidate for a RelicWeave fragment-candidate task. novelty_unconfirmed and NOT_PHYSICS_READY are explicit. There is no claim about a circumferential wall, inner surface, lip, style, material, archaeological fit, or physics readiness.
