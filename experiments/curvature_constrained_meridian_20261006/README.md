# Curvature-constrained meridian design

This is a source-only design prototype. Importing the module is inert; its one-shot SLSQP entry point is `run_constrained_design(root_ready=True)`. The approved design case is explicit in `design_cases.json`: bowl apex `(60,72)` at `u=8/12`, with foot `(24,0)`, neck start `(57,86)`, and mouth `(57,90)` unchanged; jar remains at its frozen `u=6/12` apex and existing datums. The bowl height is an engineering seed correction, not a revised historical measurement or an achieved geometry result.

The old bowl datum `(60,77.4)` cannot meet the necessary R9 pairwise bound between its apex and neck start: `D=3`, `H=8.6`, so `H²=73.96 < 4·9·3−3²=99`. The explicit 72 mm design datum gives `H=14` and `H²=196≥99`. The source evaluates this exact Fraction gate before importing SciPy. For `D=0` or `D>2R`, it records `NOT_APPLICABLE` with a reason; that formula is not reported as a pass. The jar's `D=28>18` is also `NOT_APPLICABLE`, with its regularity and curvature gates still required.

For each family, the frozen actual minimum-jerk poles are only a warm start. Exact Fraction RREF applies a pivot-only affine correction to the explicit design-case right-hand sides, with nonpivot correction coordinates set to zero, producing a compatible particular `Q0`. A second exact RREF constructs the 7 radial and 8 vertical nullspace directions, so `Q=Q0+Zα` keeps all fixed poles and declared size features exact after optimizer decimals are converted to Fractions.

SLSQP receives the complete inequality set: extracted Bezier-pole bounding boxes, nonnegative vertical derivative poles, radial direction signs around the apex, a speed lower bound of `1 mm/global-u` along each span's exact Q0 endpoint-velocity-sum direction, and all 25 Bernstein coefficients of `P_R` on spans 1–10 at `R_design=9.09 mm`. The speed bound covers the flat base and cylindrical neck without requiring `z'>0` at the C4 base join. Curvature uses local Bezier `t` and `(r/9 mm,z/9 mm)`. The objective minimizes squared pole distance from compatible Q0, scaled by 9 mm.

A future root-approved call follows the root engineering budget: at most one SLSQP call per family, 80 iterations each, absolute finite-difference step `1e-4 mm`, 60 seconds shared across design, and an 8 MiB result cap. No automatic target changes or adaptive retries occur. Candidate controls are reconstructed with exact decimal Fractions; the reference-direction speed inequalities are rechecked exactly, then the frozen driver's exact extraction and whole-span `P_R(9)` checks run. `EXACTFAIL` or `UNKNOWN` never promotes; a promoted item remains a geometry engineering candidate, not physics-ready or style-calibrated. Novelty is unconfirmed. There is no lip, inner wall, CAD, renderer, material, or total-height claim.

The frozen driver, fixed case file, and actual seed result remain untouched and are hash-pinned in the companion `vesselforge/tmp/review_20261006/curvature_constrained_meridian_20261006/source_pins.json`. SciPy distribution metadata in `third_party/vesselforge-runtime/venv` reports 1.18.1; this was read as package metadata only. This review did not import SciPy, run the optimizer, build a curve, or perform CAD or rendering. The user authorization covers only a local small test; no optimizer was run here.
