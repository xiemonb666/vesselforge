# Review freeze

This directory freezes the inputs consulted for the surface ornament route proposal and the authored design/prototype artifacts. Input files are listed as read-only references. The Python prototype has not been run; no CAD, Python, test, solver, or GPU execution is represented here.

See `FREEZE_MANIFEST.json` for roles, repository-relative paths, and SHA-256 values. `SHA256SUMS.txt` repeats each input/artifact hash and includes the manifest hash; the checksum file does not hash itself.
