# Exact curvature certificate source

This directory defines a bounded exact-rational proof run for the fixed bowl and jar outer profiles. It is source-only at this stage. `run_exact_curvature_certificate` refuses to run unless its caller explicitly supplies `root_ready=True`; no curve, polynomial, CAD model, or certificate has been generated here.

The case file is a verbatim copy of `whole_body_c2_profiles_20261006/fixed_cases.json` (SHA-256 `e1e9c3cf659dbc59d99a18c4b70694201518be4f3aba09a57806402e732cf95a`). The former profile source SHA-256 is `057233b930a2b8e0e3ef43a3568f1cb0e6e972baed97eeeeceb6459d9de8c951`; the prior finite-sample diagnostic SHA-256 is `eb60138fc559d5a06ab2b4febf82fdc6654e6bbeab84f05f847c65934ffbbd4f`.

The script independently reconstructs each degree-seven Bezier span from the exact endpoint position and first three derivatives in the fixed case. It builds Bernstein coefficients for `S=||C'||²`, `D=det(C',C'')`, and `P_R=S³-R²D²` using exact `Fraction` arithmetic. Exact degree elevation aligns `D²` with the degree-36 `S³`. Exact midpoint subdivision into four quarter-spans checks the derivative projection and records each interval's minimum control projection; all four must be strictly positive to prove `S>0`. Nonnegative coefficients certify the radius target; strict positivity of `P_3` certifies the local 3 mm normal-offset regularity condition. If the root interval coefficients do not settle the sign, exact midpoint de Casteljau subdivision supplies a complete rational interval cover. Every span reports its eight exact control points and a SHA-256 digest of their compact JSON encoding.

The run is bounded to depth 8, at most 256 checked nodes per polynomial target, at most 1024 checked nodes globally, and 30 seconds. Any unresolved interval is reported as `UNKNOWN` with its exact rational interval, Bernstein coefficients, and reason. A certified negative interval is `FAIL_CERTIFIED`. The fixed case supplies the 9 mm body/shoulder radius target, the family-specific 9 mm bowl or 8.25 mm jar base target, and the four side-wall spans per vessel for the strict 3 mm test. Lip spans receive report-only treatment with no transferred radius threshold.

The output path is `vesselforge/tmp/review_20261006/exact_curvature_certificate_20261006/exact_curvature_certificate.json`; an existing output is never overwritten. This proof scope concerns local curve regularity and the listed curvature inequalities. Global wall thickness, nonlocal intersections, material properties, and CAD/STEP results remain unknown or unclaimed. The proof method replaces the conservative ratio upper bound with a nonnegative polynomial square inequality; novelty has not been established.
