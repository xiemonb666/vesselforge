# Bowl apex–neck 必要高度界

结论：在**正则、按弧长可参数化**的子午线段上，若 (r) 全程不增、(z) 全程不减，两端切线竖直且 (|\kappa|\le1/R)，则端点水平差 (D\le2R) 必须满足

\[
H\ge\sqrt{4RD-D^2}.
\]

证明不假设角度单调。以弧长 (s) 参数化，令切线与竖直夹角为 (\theta\in[0,\pi/2])，故 (-r'=\sin\theta, z'=\cos\theta, |\theta'|\le1/R)，且两端 (\theta=0)。设 (m=\max\theta)。从0到峰值再回0的总变差及曲率界给出：任意非负函数 (f)，\(\int f(\theta)ds\ge2R\int_0^m f(v)dv\)；额外振荡只会增加该积分。取 (f=\sin\theta)，得 (D\ge2R(1-\cos m))，故 (m\le m_D=\arccos(1-D/(2R)))。再取 (f=\cos\theta-\cot(m)\sin\theta=\sin(m-\theta)/\sin m\ge0)，得

\[
H\ge D\cot m+2R\tan(m/2).
\]

右式在 (0<m\le m_D) 随 (m) 递减（导数 (R\sec^2(m/2)-D\csc^2m\le0)，在 (m_D) 为0），于是其最小值为 (2R\sin m_D=\sqrt{4RD-D^2})。饱和例是曲率分别为 (+1/R,-1/R) 的两段圆弧；它说明界可达，但必要性来自上述总变差论证，故角度来回振荡不会绕过。

代入 (D=60-57=3)、(R=9)，必须 (H\ge\sqrt{99}\approx9.95\) mm。当前 (H=86-77.4=8.6)，且 (8.6^2=73.96<99)，因此在这些语义条件下不可能满足R9。允许 (z'=0) 不构成反例：正则处它对应 (\theta=\pi/2)，到达该角至少需要 (D\ge2R=18) mm；弧长参数中的停顿（(r'=z'=0)）可删除，不改变端点位移。若允许尖点/曲率无定义的非正则段，则已不满足此曲率屏的通常前提。

新提案 apex 高度72、neck-start高度86给 (H=14>\sqrt{99})，只越过此必要界；不证明存在解，也不证明全段曲率、凸包、单调性或全局几何通过。
