# 真实器物参考目录（2026-10-04）

## 目的与证据边界

本目录为 VesselForge / PG-Frag / A12 → RelicWeave 的“碎片→历史邻片候选”服务提供一组可核对的真实器物参考。它是候选检索与参数化的证据索引，不是历史器物的完整复原数据集，也不证明生成结果具有完整历史真实性。

本次核对了五件大都会艺术博物馆（The Met）官方藏品记录。记录页公开的对象资料、馆方描述、尺寸、材料与工艺作为 **FACT_FROM_SOURCE**。根据页面列出的尺寸进行的粗略比例计算、或对页面照片能支持的宽泛外观判断，列为 **VISUAL_INFERENCE**，并注明未测量。供生成器尝试的参数和匹配策略列为 **GENERATOR_SUGGESTION**。三类证据不互相升级：照片不能补出目录未给出的精确壁厚、截面曲线、曲率半径或力学性质。

Met 各对象页标有 Public Domain，并说明开放数据及公有领域图像可免许可费用于商业与非商业用途。本目录仅保存稳定藏品页链接和文字资料，没有下载或嵌入图片。对象页提供的图像条目数见下表；页面没有为这些条目标注摄影方向、尺度标尺或正交视图，所以条目数不能视为三维覆盖度。

### 逐件证据

#### Bowl — 1971.27

**FACT_FROM_SOURCE**
- 馆方标题为 Bowl；年代为 11 世纪早期；地域为归属埃及。
- 材料字段为 Earthenware; luster-painted。尺寸为高 2 5/8 in.（6.7 cm）、直径 9 13/16 in.（24.9 cm）。
- 馆方文字说明 Fatimid 时期埃及陶器常用 luster painting，并称这件器物保留了阿拔斯风格的卷草和填隙点纹。馆方文字将器物称作 plate；数据库正式标题仍为 Bowl。
- 对象页标注 Public Domain；同页说明开放数据和公有领域图像可免许可费用于商业及非商业使用。
- 页面列出两个图像入口；入口未标注视角或尺度。

**VISUAL_INFERENCE**
- 仅按所报高与直径计算，外包络高/直径约为 0.27，可作为“浅碗/盘”候选比例线索。它不是截面曲线、内腔深度或口沿截面测量。
- 页面照片不能据此给出釉面反射率、luster 层厚度或经校准的颜色值。

**GENERATOR_SUGGESTION**
- 允许 bowl 候选携带一组有来源的浅型比例提示，以及 luster-painted / 卷草 / 点纹的独立表面标签；每个标签保留指向该藏品号的来源。
- 碎片只有绘饰证据而无剖面证据时，只建议纹饰候选，不将其升级为器形或历史归属结论。

**UNKNOWN**
- 壁厚、底足/底径、完整内外轮廓、曲率半径、胎釉配方、烧成温度、强度、光泽或色彩仪器测量均未在该记录中给出。

#### Beaker — 50.61.8

**FACT_FROM_SOURCE**
- 馆方标题为 Beaker；新石器时代 Longshan 文化；地域/文化字段为中国。
- 材料字段为 Burnished black earthenware。尺寸为高 7 5/16 in.（18.6 cm）、上口直径 5 7/8 in.（14.9 cm）。
- 页面标注 Public Domain，并给出 Met Open Access 数据和公有领域图片的免许可说明。
- 页面列出两个图像入口；没有视角标签或尺度说明。

**VISUAL_INFERENCE**
- 高/上口直径约为 1.25，说明记录尺寸的纵向范围大于开口宽度；它不确定杯壁是直筒、外撇、内收或带足。
- “黑色”和“烧光”是馆方材料字段，不构成仪器测色或表面粗糙度测量。

**GENERATOR_SUGGESTION**
- beaker 候选可保存上口直径与高度作为包络约束；将黑色烧光表面作为材质/表面标签，而不要自动附加釉层或绘饰。
- 缺少口沿、底径和侧视剖面数据时，不从两个尺寸插值出真实轮廓。

**UNKNOWN**
- 口沿形状、底部尺寸、具体曲线、壁厚、胎土成分、烧成条件、表面粗糙度、光泽度和力学性质均未知。

#### Jar — 1975.268.184（Late Jōmon）

**FACT_FROM_SOURCE**
- 馆方标题为 Jar；年代为 Late Jōmon（约公元前 2500–1000）；文化字段为 Japan。
- 材料字段为 Earthenware with incised decoration。尺寸为高 7 7/8 in.（20 cm）、直径 6 1/2 in.（16.5 cm）。
- 馆方描述称其为小型鼓腹、窄颈瓶；表面有刻纹与不常见的红色颜料；肩部与下部各有一组穿孔，可穿细绳悬挂。
- 馆方文字称器壁薄，但没有数值壁厚。页面标注 Public Domain 和 Open Access 免许可说明。
- 页面列出三个图像入口；没有标注标准视图、比例尺或完整三维信息。

**VISUAL_INFERENCE**
- “鼓腹、窄颈”属于馆方文字描述；可把它当作器形词汇证据，不能据此还原每一段曲线。
- 红色颜料是馆方文字记载；照片综合色偏、光线和屏幕显示不能替代颜料分析或色彩测量。

**GENERATOR_SUGGESTION**
- jar 候选可以提供“鼓腹 / 窄颈 / 两组悬挂孔 / 刻纹”作为可开关的形态和表面特征，但应要求碎片或查询条件支持这些特征后再组合。
- “薄壁”只能作为定性馆方注记；在没有截面量测前，不能写入毫米级壁厚或强度参数。

**UNKNOWN**
- 数值壁厚、颈口直径、孔径与精确位置、底径、完整剖面、刻纹尺寸与节奏、颜料/胎土成分、烧成参数和力学性质未知。

#### Ewer — 36.20.25

**FACT_FROM_SOURCE**
- 馆方标题为 Ewer；年代 12–13 世纪；在伊朗 Nishapur 出土。
- 材料字段为 Earthenware; molded decoration, unglazed。尺寸为高 11 in.（27.9 cm）、直径 5 3/4 in.（14.6 cm）。
- 馆方说明器身由两个带印记的半球模具制成，印记形成凸起的重复纹样；两半以湿泥结合，中央可见被抹平的接缝泥带；之后另行拉坯制作无装饰的颈和柄，并接到模制器身上。
- 页面标注 Public Domain 和 Open Access 免许可说明；页面列出四个图像入口，但未说明它们是正交视图。
- 记录文字没有说明壶嘴的几何形状；标题为 ewer，相关器形判断须谨慎。

**VISUAL_INFERENCE**
- “凸起重复纹”和“中部接缝”是馆方直接描述，不是从像素测量得出。对象页照片不能给出凸纹高度、模具节距或接缝凹凸尺寸。
- 目录只报一个直径字段，没有说明该直径对应口沿、器腹还是其他位置；不可据此生成器身截面。

**GENERATOR_SUGGESTION**
- 当前 bowl/beaker/jar 三类不足以表示带柄的注水器；若 RelicWeave 确实观察到颈/柄/壶嘴碎片，可新增 handled_ewer/pitcher 候选分支。
- 把 molded_relief 与 painted/incised 作为不同表面机制；只有碎片的起伏、断面或可靠纹饰观察支持时，才选凸纹分支。
- 生成建议应将两个半球组合接缝作为可选构造标签，而不是普遍套用到罐类。

**UNKNOWN**
- 壶嘴存在形式及精确轮廓、柄截面、器身的完整曲率、接缝厚度、凸纹尺寸、壁厚、胎土配方、烧成温度和力学性质均无数值依据。

## 对现有三类目录的修正规则

1. **把家族识别输出成候选。** bowl、beaker、jar 是检索入口，输出应带 reference_id、支持字段、未覆盖字段和不确定性；不得自动宣称“这就是某历史器物”。
2. **拆开形态、工艺与表面。** 例如“鼓腹/窄颈”属于轮廓描述，“模制凸纹/刻纹/绘饰”属于纹样工艺，“无釉/青绿釉/烧光”属于表面或材料线索。一个碎片观察不应同时决定这三类字段。
3. **只用博物馆明确报告的维度。** 当前五条记录没有提供完整剖面。只有明示的总高、指定口径/直径或定性形态可作为候选线索；缺失维度不通过照片猜值。
4. **颜色保留来源语境。** “黑色”“红色颜料”“黑绘在青绿色釉下”是馆方用语。它们不是 RGB/材质光谱，也不授权任意综合色调自动归类。
5. **纹理要有机制标签。** 凹刻、釉下绘饰、luster 绘饰、烧光和模具凸纹是不同的可见/制作线索。生成器须允许 UNKNOWN；不能把印刷纹样贴花误当成浮雕，也不能从破片单张照片判定壁面法向起伏。
6. **局部曲率只可约束邻片排序。** 对照片中单片碎片，可输出“与某候选曲率范围相容”的排序建议；没有扫描/标尺时不声称绝对曲率、壁厚或同一件器物身份。

## 需要新增家族与扫描证据

- **新增候选家族：** 带柄注水器 / ewer-pitcher。36.20.25 的馆方记录可支持带柄、分段成形与凸纹参考；它不能单独定义壶嘴外形，因为页面文字没有描述壶嘴几何。
- **为三类补充子型：** 浅碗、烧光黑陶 beaker、带穿绳孔的窄颈鼓腹罐。它们应是参考特征标签，不是新的真实性认证。
- **精确几何所需证据：** 注册比例尺的多视角摄影、正交外形轮廓，或博物馆/考古项目发布的摄影测量/结构光扫描；如需壁厚和内外表面约束，则需要断口截面测量或 CT。还要保留数据来源、坐标系、尺度校准和缺损区域标记。
- **材料/力学所需证据：** 对象级材料分析或原始检测报告。当前藏品页面没有胎土配比、釉层厚度、孔隙率、弹性模量、抗弯强度或断裂韧度，本目录不以一般陶瓷常识为单件器物填数。

本次没有引用材料科学论文来替具体器物补写材料参数：对象级页面没有给出可对照的实验结果，也没有将一般陶瓷属性外推到这些藏品。后续如加入材料论文，应标为材料/工艺背景证据，并明确它不能代替单件器物检测。
